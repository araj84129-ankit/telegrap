# ChatWave - WhatsApp Style Real-Time Chat

A real-time private chat application built with:

- Python
- Flask
- Flask-SocketIO
- SQLite
- HTML
- CSS
- JavaScript
- WebRTC

## Features

- Register account
- Login with email/mobile
- Unique username
- Case-insensitive username uniqueness
- Username search
- Private 1-to-1 chat
- Real-time messages
- SQLite message storage
- Sent tick
- Delivered double tick
- Read blue double tick
- Typing indicator
- Online/offline status
- Last seen
- Unread count
- Profile photo
- Display name
- Voice calls
- Video calls
- WebRTC signaling
- Responsive mobile UI
